## 📌 О Проекте

**MUS-MCG (MCG-V3.0)** — исследовательский веб-терминал, генератор кода и параметрический комбайн для формализации, анализа и экспорта композиторских музыкальных ядер.

Система объединяет два взаимодополняющих инструмента:
1. **Musical Core Generator (Генератор Ядер):** Интерактивный веб-интерфейс (`src/App.tsx`) и скрипт `composer_core_generator.py`, позволяющие исследовать параметры 17 композиторских стилей, проверять их устойчивость через Шлюз Алёши и экспортировать полностью автономные ZIP-архивы для Python 3.8+ без внешних библиотек.
2. **Academic Harvester (Академический Комбайн):** Аналитический модуль (`academic_harvester.py`), содержащий объектно-ориентированные классы современных композиторов академической традиции (Мартынов, Сильвестров, Пярт, Стравинский, Губайдулина, Крамб) для параметрической интеграции.

> ⚠️ **Важное уточнение по звуку:** Веб-приложение **не содержит встроенного аудио-синтезатора или проигрывателя звука в браузере** (Web Audio API не используется). Приложение является аналитическим терминалом и генератором данных/кода. Воспроизведение и генерация звуковых волн выполняются внешними программными синтезаторами или DAW на основе экспортируемого кода.

### 2. Математические формулы и эвристические модели

Математический аппарат MCG-V3.0 представляет собой авторскую систему алгоритмических моделей и композиторских эвристик Андрея Арцыбашева. Названия вроде «Hodge Core» и «AAM (Artsibashev Algebraic Morphology)» отражают концептуальные метафоры авторской музыкально-теоретической концепции, а не формальные теоремы дифференциальной геометрии.

#### А. Тензор EVRID
Каждое ядро описывается четырёхмерным тензором восприятия $\mathbf{EVRID} \in [0.0, 1.0]^4$:
- **$\mathbf{F}$ (Function)** — функциональная гармоническая основа, тональная устойчивость.
- **$\mathbf{T}$ (Tension)** — гармоническое и драматическое натяжение (диссонантность).
- **$\mathbf{D}$ (Density)** — фактурная и полифоническая плотность ткани.
- **$\mathbf{G}$ (Gravitation)** — ладовая и регистровая гравитация, бас, тяготение к устою.

#### Б. $\delta$-Оператор и показатель пиковой динамики
По аналогии с показателем TDI, параметр $\delta$ в системе MUS-MCG имеет два взаимодополняющих измерения:
- **Авторский базовый $\delta$-пик (`delta` в `cores.json`)**: экспертно откалиброванное автором эталонное значение энергетического максимума стиля ($0.0 \le \delta \le 1.0$).
- **Алгоритмический расчётный $\delta$-оператор (`calculate_delta()`)**: динамическая взвешенная свёртка четырёхмерного тензора восприятия $\mathbf{EVRID}$:
  $$\delta_{\text{calc}} = 0.3 \cdot F + 0.2 \cdot T + 0.2 \cdot D + 0.3 \cdot G$$
  Данный метод вычисляется динамически во всех сгенерированных Python-классах (`calculate_delta()`) и валидируется автоматическими тестами.

#### В. S-CORE (Инвариант Пифагора)
В генерируемых автономных пакетах векторный баланс мелодической линии и фактуры проверяется через евклидову норму:
$$\text{Resonance} = \sqrt{\text{Melody}^2 + \text{Texture}^2}$$

#### Г. Каналы NADI
Трёхканальная модель распределения голосовой энергии:
- **Ida**: нижний / медитативный / басовый регистр (Basso Profondo, Исон).
- **Pingala**: восходящий / динамический / тематический регистр (Знаменный распев, тема).
- **Sushumna**: центральный / объединяющий стержень (Соборность, унисон).

#### Д. Семантика показателя TDI и Шлюз Алёши
- **Авторский базовый TDI (`tdi`)**: экспертно откалиброванное автором значение гармоническо-фактурного баланса стиля ($0.0 \le \text{tdi} < 0.45$).
- **Расчётный TDI (`calculated_tdi`)**: динамически вычисляемый показатель по формуле:
  $$\text{TDI}_{\text{calc}} = \min\left(\frac{T \cdot D}{F + 0.1}, 1.0\right)$$
- **Шлюз Алёши (Alyosha Gate)**: правило допуска стиля к интеграции. Ядро считается гармонически устойчивым тогда и только тогда, когда:
  $$\text{TDI}_{\text{base}} < 0.45 \quad \text{и} \quad \text{TDI}_{\text{calc}} < 0.45$$
  Все 17 ядер проекта успешно проходят Шлюз Алёши.

## 📦 Экспортируемый ZIP-пакет ядра

При нажатии «Скачать ZIP» в веб-интерфейсе генерируется автономный архив, полностью готовый к использованию в любой чистой среде Python 3.8+ без установки дополнительных библиотек.

Содержимое каждого архива:
1. `<prefix>_core.py` — класс ядра с методами `calculate_tdi()`, `calculate_delta()`, `validate_s_core()`, `get_metadata()`, `generate_example()`.
2. `metadata.json` — машиночитаемый паспорт ядра со всеми параметрами, версией и датой.
3. `requirements.txt` — спецификация зависимостей (Zero external dependencies).
4. `README.md` — подробная документация конкретного стиля и инструкции.
5. `example.py` — автономный скрипт демонстрации генерации музыкальной фразы.
6. `test_core.py` — 7 модульных тестов (`unittest`), проверяющих инвариант Пифагора, Шлюз Алёши и согласованность EVRID.

## 🚀 Инструкции по запуску и тестированию

### 1. Веб-интерфейс (React + Vite)
```bash
# Установка зависимостей
npm install

# Запуск dev-сервера на порту 3000
npm run dev

# Проверка типов и линтинг
npm run lint

# Производственная сборка
npm run build
```

### 2. Модули Python
```bash
# Проверка генератора и API для Проекта 3
python3 -B composer_core_generator.py

# Проверка академического комбайна
python3 -B academic_harvester.py
```

### 3. Комплексный запуск верификационных тестов
```bash
python3 -B test_single_source_of_truth.py
```
Тестовый набор выполняет 9 всесторонних проверок:
- Валидность JSON и наличие ровно 17 записей.
- Уникальность всех идентификаторов.
- Полное соответствие типов и схемы (`EVRID`, `NADI`, `acoustic`, `color`).
- Точное числовое совпадение с зафиксированным золотым инвентарём.
- Проверка отсутствия дублирующего хардкода в коде React (`App.tsx`).
- Проверка чтения `cores.json` модулем `composer_core_generator.py`.
- Проверка чтения `cores.json` модулем `academic_harvester.py`.
- Реальное создание ZIP-архива, распаковка во временный каталог и запуск `example.py` и `test_core.py` в чистом процессе Python.
- Семантическое разделение TDI и строгое соблюдение Шлюза Алёши для всех 17 ядер.
